# Vim 光标跳转与返回

使用 `gd` 等命令跳转后，有多种方法返回原来位置。

## 跳转方法速查

| 方法 | 操作 | 说明 |
|:---|:---|:---|
| **最常用** | `Ctrl + o` | 在跳转列表中一步步**后退** |
| | `Ctrl + i` | 在跳转列表中**前进** |
| **最快往返** | `''` | 两个单引号，在当前位置和上次跳转前位置间快速跳转 |
| | ` `` ` | 两个反引号，精确定位到上次跳转的**行和列**（对 `gd` 尤其有用） |
| **标签跳转** | `Ctrl + t` | 从标签（tags）跳转后返回 |
| **编辑位置** | `g;` | 跳转到上一次**编辑**位置 |
| | `g,` | 跳转到下一次编辑位置 |

## 辅助技巧

查看跳转历史：

```vim
:jumps
```

列出跳转记录，方便了解最近的导航路径。
