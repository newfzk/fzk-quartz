# 基于windows的VictoriaLogs部署

- 测试环境 ![[hy-win-部署测试服务器#哈一机]]

[安装包下载](https://github.com/VictoriaMetrics/VictoriaMetrics/releases)

> 注意 `VictoriaMetrics` 和 `VictoriaLogs` 是同一个代码仓库 需要在release中寻找`*-victorialogs`的版本并下载windows的zip压缩包

1. 安装包上传 `C:\syslog\victoria-logs-windows-amd64-v1.24.0-victorialogs.zip`
2. 解压 `C:\syslog\victoria-logs-windows-amd64-v1.24.0-victorialogs\victoria-logs-windows-amd64-prod.exe`
3. 试运行
   1. 地址栏 输入 cmd 打开命令行
   2. 输入启动命令启动：`victoria-logs-windows-amd64-prod.exe -storageDataPath=victoria-logs-data`
   3. 浏览器测试：<http://192.168.168.189:9428/select/vmui/> 可以成功访问 启动成功
4. 配置变更
   1. 日志存储时间+日志存储最大容量(具体数值根据现场环境进行调整): `-retention.maxDiskSpaceUsageBytes=10GiB -retentionPeriod=1w`
5. 部署脚本 等`Fluent-bit`部署测试完后一起写
