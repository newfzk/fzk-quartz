## 核心概念

Linux 文本处理三剑客指 **grep**、**sed**、**awk**，是命令行下处理文本的三个核心工具。在文件去重/比较场景中，`sort` + `comm` 也是常用的组合。

## grep — 文本搜索

```bash
grep -Fxv -f b.txt a.txt   # 在 a.txt 中查找不在 b.txt 的行（差集 A-B）
```

| 选项 | 含义 |
|------|------|
| `-F` | 固定字符串匹配（不解释正则），更快 |
| `-x` | 整行匹配（不匹配子串） |
| `-v` | 反向匹配（输出不匹配的行） |
| `-f file` | 从文件中读取匹配模式 |

## sed — 流编辑器

- 非交互式文本替换、删除、插入
- 常用于批量修改配置文件和日志清洗

## awk — 文本分析

- 按列处理结构化文本（如 CSV、日志）
- 支持变量、循环、条件判断，是微型编程语言

## sort + comm — 文件比较组合

```bash
comm -3 <(sort a.txt) <(sort b.txt)   # 输出只在单方存在的行
```

| comm 选项 | 含义 |
|-----------|------|
| `-1` | 不显示第一列（只在文件 1 中） |
| `-2` | 不显示第二列（只在文件 2 中） |
| `-3` | 不显示第三列（两文件共有）= 对称差 |
| `-12` | 只显示两文件共有 = 交集 |

## 面试要点

- 三剑客各有侧重：grep 搜、sed 改、awk 分析
- 文件去重优先用 `comm -3`（更高效），备选 `grep -Fxv -f`（无需排序但更慢）
- 万行级文件用 shell 命令比编程语言更快
