# IPv4 地址分类与子网掩码

## IPv4 地址的基本形式

- 长度 **4 bytes = 32 位**
- 惯用写法：分成四个十进制数，每段范围 0–255，如 `192.0.0.1`
- IP 包头部中填写的是该地址的**二进制形式**

## 地址分类

| 类别 | 起始 | 结束 | 子网掩码 |
|---|---|---|---|
| **A** | 1.0.0.0 | 126.255.255.255 | 255.0.0.0 |
| **B** | 128.0.0.0 | 191.255.255.255 | 255.255.0.0 |
| **C** | 192.0.0.0 | 223.255.255.255 | 255.255.255.0 |

## 子网掩码的作用：划分"社区"与"房子"

IP 地址是**全球地址**，它同时识别两件事：

- **局域网（"社区"）**：网络号部分
- **主机（"房子"）**：主机号部分

每个 IP 地址的 32 位被分为前后两段，**子网掩码标记这两段的分界线**：

```
255.0.0.0  =  8 个 1 + 24 个 0
              ↓
前 8 位区分局域网，后 24 位区分主机
```

因为 A/B/C 分类是预先规定的，所以看到 IP 落在 B 类范围时，就知道它的**前 16 位是网络号、后 16 位是主机号**，无需额外查询子网掩码。

> [!info] 为什么分类地址现在不常用了
> A/B/C 分类粒度太粗、浪费严重，现代网络普遍使用 **CIDR**（无类域间路由）按需划分前缀长度（如 `/24`、`/26`）。但分类地址是理解子网掩码与路由表的历史基础，排查老系统时仍会遇到。

## 关键认知

> [!important] IP 地址识别的是网卡，不是计算机
> IP 地址分配给**网卡（NIC）**，而非整台计算机。
>
> - 接收：网卡收到网络信息后交给计算机（处理器/内存）
> - 发送：须先决定**通过哪个网卡**发送
> - 一台计算机可有多张网卡（如笔记本的以太网卡 + WiFi 网卡），因此可拥有多个 IP

这解释了很多现象：多网卡主机有多条路由、同一台机器能同时属于多个网段、绑定 IP 的服务必须指定监听的网卡。

## 相关：路由器就是多网卡主机

**路由器本质上是一台配备多张网卡的专用电脑**，它让各张网卡接入不同网络。例如一台路由器有两张网卡，地址分别是 `199.165.145.17` 和 `199.165.146.3`，就分别接入了 `199.165.145` 和 `199.165.146` 两个网络——这正是它能同时"待在"两个网段、在它们之间转发包的原因。
