## 核心概念

VFS（Virtual File System，虚拟文件系统）是 Linux 内核中的一个抽象层，为上层应用提供统一的文件操作接口，屏蔽底层不同文件系统的差异。

## 常见虚拟文件系统类型

| 文件系统 | 挂载点 | 用途 |
|----------|--------|------|
| `sysfs` | `/sys` | 内核导出硬件设备与驱动信息 |
| `proc` | `/proc` | 进程与系统内核信息（如 `/proc/cpuinfo`、`/proc/meminfo`） |
| `devtmpfs` | `/dev` | 设备节点自动管理（如 `/dev/sda`、`/dev/tty`） |
| `tmpfs` | `/run`、`/tmp` | 内存中临时文件系统，重启清空 |
| `cgroup2` | `/sys/fs/cgroup` | 控制组 v2，资源限制与监控 |

## 虚拟 vs 真实文件系统

| 特性 | 虚拟文件系统 | 真实文件系统（ext4/xfs） |
|------|-------------|------------------------|
| 存储位置 | 内存中 | 磁盘分区 |
| 持久化 | 重启消失 | 持久保存 |
| 数据来源 | 内核动态生成 | 用户写入 |
| I/O 操作 | 不涉及磁盘 I/O | 涉及磁盘读写 |

## 安全限制

虚拟文件系统通常挂载时带有 `nosuid`、`nodev`、`noexec` 安全选项，防止恶意利用。

## 面试要点

- VFS 是策略模式在内核中的经典应用，定义统一接口，各文件系统实现具体行为
- `df -h` 看到的虚拟文件系统不占磁盘空间
- 区别 `tmpfs`（内存，可换出到 swap）和 `ramfs`（纯内存，不换出）
